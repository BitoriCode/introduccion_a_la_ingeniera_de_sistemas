# Módulo 3: Consultas SQL con SELECT

## Introducción

Llegó el momento de hablar con la base de datos. El lenguaje que usamos para hacerlo se llama **SQL** (*Structured Query Language* — Lenguaje de Consulta Estructurado). Con SQL le podemos decir a la base de datos: *"dame todos los estudiantes del semestre 3"*, *"muéstrame los productos que cuestan menos de $50.000"*, *"ordéname las notas de mayor a menor"*.

> **Algo importante antes de arrancar:** SQL no distingue entre mayúsculas y minúsculas para las palabras clave. `SELECT`, `select` y `Select` son lo mismo. Por convención, escribimos las palabras clave en **MAYÚSCULAS** y los nombres de tablas y columnas en **minúsculas**.

## 1. SELECT y FROM — la consulta básica

La estructura mínima de una consulta SQL es:

```sql
SELECT columna1, columna2
FROM nombre_tabla;
```

- `SELECT` indica **qué columnas** queremos ver.
- `FROM` indica **de qué tabla** queremos los datos.
- El punto y coma `;` marca el final de la sentencia.

### Seleccionar columnas específicas

```sql
SELECT nombre, apellido
FROM estudiantes;
```

**Resultado:**

| nombre | apellido |
|---|---|
| Camila | Rodríguez |
| Andrés | Martínez |
| Valentina | López |
| ... | ... |

### Seleccionar todas las columnas con `*`

El asterisco `*` es un comodín que significa "todas las columnas":

```sql
SELECT *
FROM estudiantes;
```

> **Buena práctica:** Usar `SELECT *` está bien para explorar datos rápidamente. En aplicaciones reales, es mejor listar las columnas explícitamente para evitar traer datos innecesarios.

### Alias de columnas con AS

Podemos cambiar el nombre que aparece en el resultado usando `AS`:

```sql
SELECT nombre AS "Nombre del estudiante", promedio AS "Promedio acumulado"
FROM estudiantes;
```

**Resultado:**

| Nombre del estudiante | Promedio acumulado |
|---|---|
| Camila | 4.2 |
| Andrés | 3.8 |

## 2. WHERE — filtrar filas

`WHERE` nos permite especificar una condición. Solo se devuelven las filas donde la condición es verdadera.

```sql
SELECT columnas
FROM tabla
WHERE condición;
```

### Operadores de comparación

| Operador | Significado | Ejemplo |
|---|---|---|
| `=` | Igual a | `semestre = 3` |
| `<>` o `!=` | Diferente de | `ciudad <> 'Bogotá'` |
| `>` | Mayor que | `promedio > 4.0` |
| `<` | Menor que | `promedio < 3.0` |
| `>=` | Mayor o igual que | `semestre >= 3` |
| `<=` | Menor o igual que | `promedio <= 3.5` |

### Ejemplos

**¿Qué estudiantes son del semestre 3?**

```sql
SELECT nombre, apellido, semestre
FROM estudiantes
WHERE semestre = 3;
```

| nombre | apellido | semestre |
|---|---|---|
| Camila | Rodríguez | 3 |
| Sebastián | García | 3 |

---

**¿Qué estudiantes tienen promedio mayor a 4.0?**

```sql
SELECT nombre, apellido, promedio
FROM estudiantes
WHERE promedio > 4.0;
```

| nombre | apellido | promedio |
|---|---|---|
| Camila | Rodríguez | 4.2 |
| Valentina | López | 4.7 |
| Daniela | Torres | 4.5 |
| Juan | Díaz | 4.8 |

---

**¿Qué estudiantes son de Bogotá?**

```sql
SELECT nombre, apellido, ciudad
FROM estudiantes
WHERE ciudad = 'Bogotá';
```

> **Importante:** Los valores de texto van entre **comillas simples** `' '`. Los números van sin comillas.

## 3. Operadores lógicos: AND, OR, NOT

Permiten combinar varias condiciones.

### AND — se deben cumplir TODAS las condiciones

```sql
SELECT nombre, ciudad, semestre
FROM estudiantes
WHERE ciudad = 'Bogotá' AND semestre = 3;
```

| nombre | ciudad | semestre |
|---|---|---|
| Camila | Bogotá | 3 |

Solo aparece Camila — es la única de Bogotá que está en semestre 3.

---

### OR — se debe cumplir AL MENOS UNA condición

```sql
SELECT nombre, ciudad
FROM estudiantes
WHERE ciudad = 'Cali' OR ciudad = 'Barranquilla';
```

| nombre | ciudad |
|---|---|
| Sebastián | Cali |
| Laura | Barranquilla |
| Juan | Cali |

---

### NOT — niega una condición

```sql
SELECT nombre, ciudad
FROM estudiantes
WHERE NOT ciudad = 'Bogotá';
```

Equivalente a `WHERE ciudad <> 'Bogotá'` — devuelve todos los que **no** son de Bogotá.

---

### Combinando AND y OR — usar paréntesis

Cuando se mezclan `AND` y `OR`, los paréntesis son fundamentales para que la condición sea la que queremos:

```sql
-- Estudiantes de Bogotá o Medellín que tengan promedio >= 4.0
SELECT nombre, ciudad, promedio
FROM estudiantes
WHERE (ciudad = 'Bogotá' OR ciudad = 'Medellín') AND promedio >= 4.0;
```

| nombre | ciudad | promedio |
|---|---|---|
| Camila | Bogotá | 4.2 |
| Valentina | Bogotá | 4.7 |
| Daniela | Medellín | 4.5 |

> **Regla:** Sin paréntesis, `AND` tiene precedencia sobre `OR` (como la multiplicación sobre la suma en aritmética). Usar paréntesis siempre que haya ambos.

---

## 4. BETWEEN — rangos de valores

`BETWEEN` permite filtrar por un rango de forma más legible que usando `>= AND <=`.

```sql
-- Estudiantes con promedio entre 3.5 y 4.5 (inclusive en ambos extremos)
SELECT nombre, promedio
FROM estudiantes
WHERE promedio BETWEEN 3.5 AND 4.5;
```

| nombre | promedio |
|---|---|
| Camila | 4.2 |
| Andrés | 3.8 |
| Daniela | 4.5 |
| Laura | 3.9 |

---

## 5. IN — lista de valores

`IN` permite filtrar por una lista de valores, evitando escribir múltiples `OR`:

```sql
-- Sin IN (incómodo):
WHERE ciudad = 'Bogotá' OR ciudad = 'Cali' OR ciudad = 'Medellín'

-- Con IN (limpio):
SELECT nombre, ciudad
FROM estudiantes
WHERE ciudad IN ('Bogotá', 'Cali', 'Medellín');
```

| nombre | ciudad |
|---|---|
| Camila | Bogotá |
| Andrés | Medellín |
| Valentina | Bogotá |
| Sebastián | Cali |
| Daniela | Medellín |
| Felipe | Bogotá |
| Juan | Cali |

---

### NOT IN — excluir una lista

```sql
SELECT nombre, ciudad
FROM estudiantes
WHERE ciudad NOT IN ('Bogotá', 'Medellín');
```

Devuelve solo los de Cali y Barranquilla.

---

## 6. LIKE — búsqueda de patrones en texto

`LIKE` sirve para buscar textos que coincidan con un patrón. Usa dos comodines:

| Comodín | Significado |
|---|---|
| `%` | Cero o más caracteres cualquiera |
| `_` | Exactamente un carácter cualquiera |

```sql
-- Nombres que empiezan con 'Ca'
SELECT nombre FROM estudiantes WHERE nombre LIKE 'Ca%';
-- Resultado: Camila

-- Nombres que terminan en 'a'
SELECT nombre FROM estudiantes WHERE nombre LIKE '%a';
-- Resultado: Camila, Valentina, Daniela, Laura

-- Nombres que contienen 'an'
SELECT nombre FROM estudiantes WHERE nombre LIKE '%an%';
-- Resultado: Valentina, Sebastián

-- Apellidos de exactamente 5 caracteres
SELECT apellido FROM estudiantes WHERE apellido LIKE '_____';
-- Resultado: Díaz (no — tiene 4), López (5 caracteres) ✓
```

> **Nota:** `LIKE` generalmente no distingue mayúsculas de minúsculas en MySQL. En PostgreSQL sí. Usar `ILIKE` en PostgreSQL para búsquedas insensibles a mayúsculas.

## 7. IS NULL / IS NOT NULL

`NULL` en SQL significa "valor desconocido o ausente". No es cero ni vacío — es ausencia de dato.

> **No se puede comparar con `=`**: `WHERE promedio = NULL` **no funciona**. Se debe usar `IS NULL`.

```sql
-- Estudiantes sin promedio registrado
SELECT nombre
FROM estudiantes
WHERE promedio IS NULL;

-- Estudiantes con promedio registrado
SELECT nombre
FROM estudiantes
WHERE promedio IS NOT NULL;
```

## 8. ORDER BY — ordenar resultados

`ORDER BY` ordena las filas del resultado por una o más columnas.

```sql
SELECT nombre, promedio
FROM estudiantes
ORDER BY promedio;           -- ascendente por defecto (ASC)

SELECT nombre, promedio
FROM estudiantes
ORDER BY promedio DESC;      -- descendente

-- Ordenar por ciudad (A-Z) y dentro de cada ciudad por promedio (mayor a menor)
SELECT nombre, ciudad, promedio
FROM estudiantes
ORDER BY ciudad ASC, promedio DESC;
```

**Resultado del último ejemplo:**

| nombre | ciudad | promedio |
|---|---|---|
| Laura | Barranquilla | 3.9 |
| Valentina | Bogotá | 4.7 |
| Camila | Bogotá | 4.2 |
| Felipe | Bogotá | 3.1 |
| Juan | Cali | 4.8 |
| Sebastián | Cali | 2.9 |
| Daniela | Medellín | 4.5 |
| Andrés | Medellín | 3.8 |

---

## 9. LIMIT y OFFSET — paginar resultados

`LIMIT` restringe cuántas filas devuelve la consulta. `OFFSET` indica desde qué fila empezar a contar.

```sql
-- Los 3 estudiantes con mayor promedio
SELECT nombre, promedio
FROM estudiantes
ORDER BY promedio DESC
LIMIT 3;
```

| nombre | promedio |
|---|---|
| Juan | 4.8 |
| Valentina | 4.7 |
| Daniela | 4.5 |

```sql
-- Del cuarto al sexto lugar (paginación: página 2 de grupos de 3)
SELECT nombre, promedio
FROM estudiantes
ORDER BY promedio DESC
LIMIT 3 OFFSET 3;
```

| nombre | promedio |
|---|---|
| Camila | 4.2 |
| Laura | 3.9 |
| Andrés | 3.8 |

---

## 10. DISTINCT — eliminar duplicados

`DISTINCT` elimina las filas repetidas del resultado.

```sql
-- ¿Qué ciudades están representadas en la tabla? (sin repetir)
SELECT DISTINCT ciudad
FROM estudiantes;
```

| ciudad |
|---|
| Bogotá |
| Medellín |
| Cali |
| Barranquilla |

Sin `DISTINCT`, Bogotá, Medellín y Cali aparecerían varias veces.

---

## 11. Expresiones y cálculos en SELECT

Se pueden hacer operaciones matemáticas directamente en la consulta:

```sql
-- Mostrar el promedio multiplicado por 5 (equivalente a nota sobre 5)
SELECT nombre, promedio, promedio * 5 AS "Nota sobre 25"
FROM estudiantes;
```

| nombre | promedio | Nota sobre 25 |
|---|---|---|
| Camila | 4.2 | 21.0 |
| Andrés | 3.8 | 19.0 |

```sql
-- Operaciones con textos: concatenar nombre y apellido
SELECT CONCAT(nombre, ' ', apellido) AS nombre_completo
FROM estudiantes;
```

| nombre_completo |
|---|
| Camila Rodríguez |
| Andrés Martínez |

## 12. Orden de escritura de una consulta SELECT

Una consulta completa se escribe en este orden:

```sql
SELECT   columnas
FROM     tabla
WHERE    condición
ORDER BY columna ASC/DESC
LIMIT    n OFFSET m;
```

> **Importante:** El orden importa. No se puede escribir `WHERE` antes de `FROM`.

### Ejemplo completo

*¿Cuáles son los 3 estudiantes de Bogotá con mejor promedio?*

```sql
SELECT nombre, apellido, promedio
FROM estudiantes
WHERE ciudad = 'Bogotá'
ORDER BY promedio DESC
LIMIT 3;
```

| nombre | apellido | promedio |
|---|---|---|
| Valentina | López | 4.7 |
| Camila | Rodríguez | 4.2 |
| Felipe | Ramírez | 3.1 |

## Resumen

| Cláusula | ¿Qué hace? |
|---|---|
| `SELECT columnas` | Elige qué columnas mostrar |
| `SELECT *` | Muestra todas las columnas |
| `AS` | Le da un alias (nombre temporal) a una columna |
| `FROM tabla` | Indica de dónde vienen los datos |
| `WHERE condición` | Filtra filas según una condición |
| `AND` / `OR` / `NOT` | Combina condiciones |
| `BETWEEN a AND b` | Filtra por rango (inclusive) |
| `IN (lista)` | Filtra por lista de valores |
| `LIKE 'patrón%'` | Búsqueda de texto con comodines |
| `IS NULL` / `IS NOT NULL` | Verifica si un valor está ausente |
| `ORDER BY col DESC` | Ordena el resultado |
| `LIMIT n OFFSET m` | Limita y pagina el resultado |
| `DISTINCT` | Elimina filas duplicadas |
