# Módulo 1: Fundamentos de HTML

## Bienvenidos a este módulo

Es un gusto tenerlos acá en este módulo de desarrollo web. Vamos a arrancar desde cero, con calma y paso a paso, para que todos quedemos con las bases bien puestas. En esta primera parte nos vamos a enfocar en **HTML** (*HyperText Markup Language*), que es ni más ni menos que el lenguaje con el que se estructura todo lo que vemos en una página web.

> **Dato clave:** HTML no es un lenguaje de programación, es un **lenguaje de marcado**. Es decir, le dice al navegador *qué* mostrar, pero no *cómo* comportarse. Para eso después usaremos JavaScript.

---

## 1. ¿Qué es HTML y para qué sirve?

Imagínense que una página web es como una casa:

- **HTML** es la estructura: las paredes, el techo, las puertas y ventanas.
- **JavaScript** es la electricidad y la plomería: lo que hace que las cosas funcionen e interactúen.

En este módulo nos concentramos en construir la casa (HTML) y en hacerla funcionar (JavaScript).

### ¿Cómo funciona?

Cuando ustedes abren una página web en el navegador (Chrome, Firefox, Edge, etc.), el navegador descarga un archivo `.html`, lo lee y lo **renderiza** (lo dibuja en pantalla). Ese archivo contiene **etiquetas** que le indican al navegador qué elementos mostrar.

---

## 2. Estructura básica de un documento HTML

Todo documento HTML tiene una estructura mínima. Vamos a verla:

```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página</title>
</head>
<body>
    <h1>¡Hola mundo!</h1>
    <p>Esta es mi primera página web.</p>
</body>
</html>
```

### Desglose de cada parte:

| Etiqueta | ¿Qué hace? |
|---|---|
| `<!DOCTYPE html>` | Le dice al navegador que estamos usando HTML5 (la versión actual). |
| `<html lang="es">` | Elemento raíz del documento. `lang="es"` indica que está en español. |
| `<head>` | Contiene metadatos (información sobre la página que no se ve directamente). |
| `<meta charset="UTF-8">` | Define la codificación de caracteres. Con UTF-8 podemos usar tildes y eñes sin problema. |
| `<meta name="viewport" ...>` | Hace que la página se vea bien en celulares y tablets. |
| `<title>` | El título que aparece en la pestaña del navegador. |
| `<body>` | Aquí va **todo** el contenido visible de la página. |

> **Nota:** Siempre abran y cierren sus etiquetas. Si abren `<p>`, deben cerrar con `</p>`. Hay excepciones, pero esa es la regla general.

## 3. Etiquetas de texto

HTML tiene varias etiquetas para manejar texto. Estas son las más comunes:

### Encabezados

Van del `<h1>` (el más importante) al `<h6>` (el menos importante):

```html
<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Sub-subtítulo</h3>
<h4>Nivel 4</h4>
<h5>Nivel 5</h5>
<h6>Nivel 6</h6>
```

> **Buena práctica:** Solo usen **un** `<h1>` por página. Piénsenlo como el título de un libro: solo hay uno.

### Párrafos y formato de texto

```html
<p>Este es un párrafo normal. Así se escribe la mayoría del texto en una página.</p>

<p>Podemos poner texto en <strong>negrita</strong> para resaltar algo importante.</p>

<p>También podemos usar <em>cursiva</em> para dar énfasis.</p>

<p>Y si necesitamos un <br> salto de línea dentro de un párrafo, usamos la etiqueta br.</p>

<hr>
<!-- La etiqueta hr dibuja una línea horizontal, como la de arriba -->
```

| Etiqueta | Resultado |
|---|---|
| `<strong>` | **Texto en negrita** (tiene importancia semántica) |
| `<em>` | *Texto en cursiva* (énfasis) |
| `<br>` | Salto de línea (no necesita etiqueta de cierre) |
| `<hr>` | Línea horizontal separadora |

## 4. Listas

Tenemos dos tipos principales de listas:

### Lista desordenada (con viñetas)

```html
<ul>
    <li>Bandeja paisa</li>
    <li>Ajiaco</li>
    <li>Sancocho</li>
    <li>Arepa de choclo</li>
</ul>
```

### Lista ordenada (con números)

```html
<ol>
    <li>Prender el computador</li>
    <li>Abrir el editor de código</li>
    <li>Crear un archivo .html</li>
    <li>Escribir el código</li>
    <li>Abrir en el navegador</li>
</ol>
```

> **Para recordar:** `ul` = *unordered list* (desordenada), `ol` = *ordered list* (ordenada), `li` = *list item* (elemento de la lista).

## 5. Enlaces (Links)

Los enlaces son lo que hace que la web sea *web*. Permiten navegar de una página a otra:

```html
<!-- Enlace a otra página web -->
<a href="https://www.ejemplo.com">Visitar Ejemplo</a>

<!-- Enlace a otra página de nuestro sitio -->
<a href="contacto.html">Ir a Contacto</a>

<!-- Enlace que abre en una nueva pestaña -->
<a href="https://www.ejemplo.com" target="_blank" rel="noopener noreferrer">
    Abrir en nueva pestaña
</a>
```

### Atributos importantes:

- `href`: La URL o ruta a donde lleva el enlace.
- `target="_blank"`: Abre el enlace en una nueva pestaña.
- `rel="noopener noreferrer"`: Atributo de seguridad que se recomienda usar siempre con `target="_blank"`.

## 6. Imágenes

Para mostrar imágenes usamos la etiqueta `<img>`:

```html
<!-- Imagen local -->
<img src="fotos/mi-foto.jpg" alt="Descripción de la foto" width="400">

<!-- Imagen desde internet -->
<img src="https://www.ejemplo.com/imagen.png" alt="Logo de ejemplo">
```

### Atributos:

- `src`: La ruta o URL de la imagen.
- `alt`: Texto alternativo que describe la imagen. **Siempre pónganlo**, es importante para accesibilidad y para cuando la imagen no carga.
- `width` / `height`: Ancho y alto en píxeles (opcional).

> **Importante:** La etiqueta `<img>` es **auto-cerrada**, no necesita `</img>`.

## 7. Tablas

Las tablas se usan para mostrar datos organizados en filas y columnas:

```html
<table>
    <thead>
        <tr>
            <th>Nombre</th>
            <th>Ciudad</th>
            <th>Semestre</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Camila</td>
            <td>Bogotá</td>
            <td>5to</td>
        </tr>
        <tr>
            <td>Andrés</td>
            <td>Medellín</td>
            <td>3ro</td>
        </tr>
        <tr>
            <td>Valentina</td>
            <td>Cali</td>
            <td>7mo</td>
        </tr>
    </tbody>
</table>
```

### Etiquetas de tablas:

| Etiqueta | Significado |
|---|---|
| `<table>` | Contenedor de la tabla |
| `<thead>` | Encabezado de la tabla |
| `<tbody>` | Cuerpo de la tabla |
| `<tr>` | Fila (*table row*) |
| `<th>` | Celda de encabezado (*table header*) |
| `<td>` | Celda de dato (*table data*) |

## 8. Formularios

Los formularios son muy importantes porque permiten al usuario **enviar información**. Más adelante los conectaremos con JavaScript.

```html
<form>
    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre" name="nombre" placeholder="Escriba su nombre">

    <br><br>

    <label for="correo">Correo electrónico:</label>
    <input type="email" id="correo" name="correo" placeholder="ejemplo@correo.com">

    <br><br>

    <label for="edad">Edad:</label>
    <input type="number" id="edad" name="edad" min="15" max="99">

    <br><br>

    <label for="ciudad">Ciudad:</label>
    <select id="ciudad" name="ciudad">
        <option value="">Seleccione una ciudad</option>
        <option value="bogota">Bogotá</option>
        <option value="medellin">Medellín</option>
        <option value="cali">Cali</option>
        <option value="barranquilla">Barranquilla</option>
    </select>

    <br><br>

    <label for="comentarios">Comentarios:</label>
    <br>
    <textarea id="comentarios" name="comentarios" rows="4" cols="40"
        placeholder="Escriba sus comentarios aquí..."></textarea>

    <br><br>

    <button type="submit">Enviar</button>
</form>
```

### Tipos de `<input>` más comunes:

| Tipo | Descripción |
|---|---|
| `text` | Campo de texto libre |
| `email` | Valida que sea un correo electrónico |
| `password` | Oculta los caracteres escritos |
| `number` | Solo permite números |
| `date` | Selector de fecha |
| `checkbox` | Casilla de verificación |
| `radio` | Botón de opción (selección única) |
| `file` | Permite subir archivos |

## 9. Contenedores: `<div>` y `<span>`

Estas dos etiquetas son **contenedores genéricos**. No tienen un significado visual por sí solas, pero son muy útiles para agrupar elementos:

```html
<!-- div: contenedor de bloque (ocupa todo el ancho) -->
<div>
    <h2>Sección de noticias</h2>
    <p>Aquí van las noticias del día.</p>
</div>

<!-- span: contenedor en línea (no rompe el flujo del texto) -->
<p>El precio es <span>$50.000</span> pesos.</p>
```

## 10. HTML Semántico

El HTML moderno nos da etiquetas con **significado claro**. Usarlas hace que nuestro código sea más legible y accesible:

```html
<header>
    <h1>Mi Sitio Web</h1>
    <nav>
        <a href="index.html">Inicio</a>
        <a href="acerca.html">Acerca de</a>
        <a href="contacto.html">Contacto</a>
    </nav>
</header>

<main>
    <section>
        <h2>Bienvenidos</h2>
        <p>Contenido principal de la página.</p>
    </section>

    <article>
        <h2>Noticia del día</h2>
        <p>Hoy aprendimos HTML y nos fue muy bien.</p>
    </article>

    <aside>
        <h3>Datos curiosos</h3>
        <p>HTML fue creado por Tim Berners-Lee en 1991.</p>
    </aside>
</main>

<footer>
    <p>&copy; 2026 - Universidad. Todos los derechos reservados.</p>
</footer>
```

### Etiquetas semánticas principales:

| Etiqueta | Uso |
|---|---|
| `<header>` | Encabezado de la página o sección |
| `<nav>` | Navegación principal |
| `<main>` | Contenido principal (solo uno por página) |
| `<section>` | Sección temática |
| `<article>` | Contenido independiente (noticias, posts) |
| `<aside>` | Contenido relacionado pero secundario |
| `<footer>` | Pie de página |

---

## 11. Atributos globales útiles

Estos atributos se pueden usar en **cualquier** etiqueta HTML:

| Atributo | Uso | Ejemplo |
|---|---|---|
| `id` | Identificador único del elemento | `<div id="menu">` |
| `class` | Clase para agrupar elementos similares | `<p class="destacado">` |
| `title` | Tooltip al pasar el mouse | `<abbr title="HyperText Markup Language">HTML</abbr>` |
| `hidden` | Oculta el elemento | `<p hidden>No me ven</p>` |
